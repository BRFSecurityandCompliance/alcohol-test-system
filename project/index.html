Alcohol Testing System

ระบบตรวจวัดปริมาณแอลกอฮอล์ผ่าน QR Code

ระบบฟอร์มกรอกผลตรวจสำหรับหน้างาน + แดชบอร์ดแอดมินสำหรับจัดการข้อมูล. ผู้ใช้สแกน QR เพื่อระบุสถานที่อัตโนมัติ ไม่ต้อง login.

Stack
HTML + Supabase + GitHub
Sites
12 สถานที่
Storage
Supabase (PostgreSQL)
Admin
admin-login.html
ระบบนี้เชื่อมต่อ Supabase แล้ว — ข้อมูลจะถูกบันทึกใน PostgreSQL จริง. ใช้ localStorage เป็น cache เพื่อ performance และ offline support. กดลิงก์ด้านล่างเพื่อใช้งาน.
