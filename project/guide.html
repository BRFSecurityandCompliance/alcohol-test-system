👣 ขั้นตอนการใช้งาน (สำหรับผู้ใช้)
1
📱

สแกน QR Code

ใช้กล้องโทรศัพท์สแกน QR Code ที่ติดไว้ ณ จุดตรวจ ระบบจะเปิดฟอร์มให้อัตโนมัติ

2
📝

กรอกข้อมูล

กรอกชื่อ-นามสกุล แผนก และบริษัท หรือค้นหาด้วยรหัสพนักงานเพื่อเติมข้อมูลอัตโนมัติ

3
🍺

เลือกผลตรวจ

กดเลือก 0% หรือ > 0% พร้อมระบุค่า mg% ถ้าตรวจพบแอลกอฮอล์

4
📷

ถ่ายรูปเครื่องตรวจ

ถ่ายรูปหน้าจอเครื่องตรวจแสดงผล ระบบประทับวันที่ เวลา และสถานที่ลงบนรูปอัตโนมัติ

5
✅

บันทึกสำเร็จ

กด "ส่งข้อมูล" ระบบบันทึกทันทีและส่งไปยัง Admin Panel โดยอัตโนมัติ

💡 ค้นหาด้วยรหัสพนักงาน
กรอก Employee ID แล้วกด "ค้นหา" ระบบเติมชื่อ แผนก บริษัทให้อัตโนมัติ
📸 รูปจะมีข้อมูลกำกับ
รูปที่ถ่ายจะมีวัน เวลา และชื่อสถานที่ประทับไว้อัตโนมัติ ไม่ต้องจำ
📶 ออฟไลน์ได้
หากไม่มีสัญญาณอินเทอร์เน็ต ระบบบันทึกไว้ในเครื่องก่อน แล้วซิงค์เองเมื่อออนไลน์

📋 คำอธิบายสถานะ

    ผล 0%
    ไม่ตรวจพบแอลกอฮอล์ — อนุญาตให้เข้างาน
  • ✕
    ตรวจพบแอลกอฮอล์
    ต้องบันทึกการดำเนินการ (ส่งกลับบ้าน / พักงาน)
  • ⚠
    รอดำเนินการ
    มีผลไม่ผ่านที่ยังไม่ได้ดำเนินการ — ต้องตรวจสอบ
  • 🔁
    ตรวจซ้ำ (Re-test)
    ผู้ใช้ที่ผลไม่ผ่านต้องรอแล้วตรวจซ้ำ
  • 📊
    Watchlist
    พนักงานที่ตรวจไม่ผ่านบ่อยครั้ง — ระบบแจ้งเตือนอัตโนมัติ
⭐ สำหรับผู้ดูแลระบบ (Admin) 🔒
👤

จัดการผู้ใช้งาน

  • เพิ่ม / แก้ไข / ลบผู้ใช้
  • กำหนดบทบาท (Super / Manager / Viewer)
  • ค้นหาและดูประวัติพนักงาน
  • รายการเฝ้าระวัง (Watchlist)
📍

จัดการจุดตรวจ

  • เพิ่มจุดตรวจใหม่
  • Generate QR Code อัตโนมัติ
  • Download QR เป็น PNG
  • นำเข้าข้อมูลผ่าน CSV
📋

ดูประวัติการตรวจ

  • ดูผลตรวจทั้งหมด
  • กรองตามวันที่ / ผู้ใช้ / จุดตรวจ
  • ส่งออกข้อมูล (Export CSV)
  • ดูรูปภาพและรายละเอียด
⚙️

ตั้งค่าระบบ

  • ตั้งเกณฑ์แอลกอฮอล์
  • จัดการกะทำงาน
  • ช่องทางแจ้งเตือน
  • Audit Log ทุกการกระทำ
📅 ตัวอย่างรายงานผลตรวจ
วันที่ เวลา ชื่อ แผนก บริษัท จุดตรวจ ผลตรวจ การดำเนินการ
15/05/6809:15สมชาย ใจดีขนส่งบริษัท Aปทุมธานี 0%—
15/05/6809:18สมหญิง รักดีคลังสินค้าบริษัท Bรังสิต 0%—
15/05/6809:22มานะ ตั้งใจขนส่งบริษัท Aนวนคร 50 mg% ส่งกลับบ้าน
